# Evidence — run by run

The PM's findings from each live run, newest first. A backlog row cites the
section here that diagnosed it (`#NN`), so a coding agent reads the diagnosis
instead of re-deriving it. Coding agents never edit this file.

## Run N — YYYY-MM-DD — <inputs> on `<base>` @ <sha>

- **What ran:** inputs, configuration, model(s), cost.
- **Verdict:** pass / fail per owner note (see `owner-notes.md`), then the
  scores.
- **Findings:** one bullet per miss, sorted into *product*, *instrument*,
  *evaluation* or *reference drift*, each with numbers and the artifact that
  shows it, and the row it became (`#NN`).
