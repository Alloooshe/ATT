# Briefs

The PM writes one brief per goal in *goal mode*
(`.claude/skills/team-pm/references/goal-mode.md`): `docs/briefs/<slug>.md`, at
most about two pages. It covers the goal, the research, the options compared,
the recommendation, the plan as backlog rows, the risks and the sources. Rows
filed from a brief link to it in *where to start*, so coding agents don't
re-research.
